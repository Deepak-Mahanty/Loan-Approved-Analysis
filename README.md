Loan Approval Analysis

Project Overview

This project analyses loan applicant data to explore approval patterns and examine how applicant characteristics relate to loan approval outcomes. It uses Python for data analysis and exploration and SQL to query applicant data and evaluate approval trends.

Business Objectives

* Examine loan approval rates across education categories.
* Compare approval outcomes based on credit history.
* Analyse applicant income in relation to education categories.
* Explore approval patterns across property areas and education levels.
* Compare approval rates for self-employed and non-self-employed applicants by credit history.

Tools & Technologies

* Python: Data analysis and exploration
* Pandas & NumPy: Data manipulation and preparation
* Matplotlib & Seaborn: Data visualisation
* SQL: Filtering, grouping, aggregation, and approval-rate analysis
* Power BI: Planned dashboard visualisation, if added

Analysis Workflow

1. Prepare and inspect the applicant dataset.
2. Explore applicant characteristics and loan approval outcomes.
3. Use SQL queries to calculate and compare approval rates across relevant categories.
4. Interpret the results and identify patterns that may help explain loan approval outcomes.
